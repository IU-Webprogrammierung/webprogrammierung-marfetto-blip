<h1>Portfolio Project &ndash; Web-Programming (DLBUXPWP01)</h1>
<p dir="auto">This repository contains my personal portfolio project developed as part of the IU International University course <strong>"Web-Programming (DLBUXPWP01)"</strong>. The aim was to design and implement a fully responsive, accessible, and aesthetically appealing portfolio website that showcases both personal and professional aspects, with a strong focus on real-world UX design projects.</p>

<h2 id="project-concept" dir="auto">Project Concept</h2>
<p dir="auto">The core idea behind this project was to build a <strong>static website</strong> that presents myself, my background, and my selected design projects in a professional and engaging way. The focus was on delivering a <strong>clear structure, appealing visuals, and technical precision</strong> using only HTML, CSS, and JavaScript &ndash; without the use of frameworks. The design is intended to appeal to potential employers and demonstrate my capability to combine <strong>aesthetic design</strong> with <strong>solid technical execution</strong>.</p>

<h2 id="key-features" dir="auto">Key Features &amp; Achievements</h2>
<ul dir="auto" type="disc">
<li><strong>Hand-written, semantic HTML5 code</strong> using elements like <code>&lt;header&gt;</code>, <code>&lt;nav&gt;</code>, <code>&lt;main&gt;</code>, <code>&lt;section&gt;</code>, <code>&lt;article&gt;</code>, <code>&lt;figure&gt;</code>, and <code>&lt;footer&gt;</code>and&nbsp;<strong>modular CSS</strong> with custom properties (variables) for colors and consistent theming across <code>general_style.css</code>, <code>header.css</code>, <code>footer.css</code>, and <code>fonts.css</code></li>
<li><strong>Advanced CSS animations and transitions:</strong>
<ul>
<li>Image hover effects in project overview with smooth transition from photo to project name</li>
<li>Zoom animations on hover over individual project images for enhanced interactivity</li>
<li>Subtle hover effects throughout the site for improved user feedback</li>
</ul>
</li>
<li><strong>Dynamic viewport-specific Grid layouts:</strong>&nbsp;Custom CSS Grid configurations for each section, optimized separately for desktop, tablet, and smartphone viewports</li>
<li><strong>Comprehensive accessibility features:</strong>
<ul>
<li>Meaningful ARIA labels throughout the site</li>
<li>Descriptive alt texts for all images</li>
<li>Sufficient color contrast ratios for readability</li>
</ul>
</li>
<li><strong>Consistent design language</strong>&nbsp;with cohesive visual elements and professional typography hierarchy</li>
<li><strong>Custom branding:</strong>&nbsp;Creation of logo (MH) and harmonious color scheme for the portfolio website</li>
<li><strong>Performance optimization:</strong>&nbsp;Custom fonts stored locally instead of using external CDNs for faster loading times and better performance</li>
<li><strong>Dynamic footer component:</strong>&nbsp;Footer externalized and dynamically loaded via JavaScript (<code>loadFooter.js</code>) for better code reusability and maintainability</li>
<li><strong>Advanced&nbsp;Menu:</strong>&nbsp;Sophisticated and visually appealing menu implementation with smooth interactions</li>
<li><strong>Interactive contact form:</strong>&nbsp;HTML5 validation with confirmation message upon successful submission</li>
<li><strong>"Back to top" functionality:</strong>&nbsp;Convenient button at the end of each page for easy navigation back to the top</li>
<li><strong>Version control:</strong>&nbsp;Regular commits documenting new features and project progress in the GitHub repository, using branches for feature development and testing&nbsp;</li>
</ul>

<h3 id="approach" dir="auto">Approach</h3>
<ul dir="auto" type="disc">
<li><strong>Desktop-first strategy </strong>to take full advantage of layout space and gradually adapted down for smaller devices<strong><br /></strong></li>
<li><strong>Flexbox and CSS Grid</strong> for flexible, modern layouts across all screen sizes</li>
<li>Modular CSS files (<code>general_style.css</code>, <code>header.css</code>, <code>footer.css</code>, <code>fonts.css</code>) for better organization and maintainability</li>
<li>Special attention to accessibility, readability, spacing, and touch targets on mobile devices</li>
<li>Fluid typography and responsive images for seamless scaling</li>
</ul>
<h3 id="approach" dir="auto">Obsticles</h3>
<ul dir="auto" type="disc">
<li>Google Lighthouse rated all pages in desktop voew&nbsp;with 90-100 points in performance, accessibility and best practices. However: In the mobile view, 90% performance was not achieved on all pages. Although the following points were attempted:
<ul>
<li>
<p>Implementing the font in the local folder</p>
</li>
<li>
<p>Reducing image sizes and trying out multiple image formats (webp, jpg, svg, png).</p>
</li>
<li>
<p>Defer/Async: loadFooter.js with defer</p>
</li>
<li>Tried lazy loading on images</li>
<li>Tried&nbsp;<strong><code>font-display: swap</code></strong></li>
</ul>
</ul>
<h3 id="approach" dir="auto">Thoughtful Design Decision:</h3>
<ul>
<li>Fonts integrated locally into the file to improve website performance</li>
<li>As a rule, image sizes were kept to a maximum of 100kb. Exceptions up to 1mb per image were made for portfolio images showcasing detailed UX work, as high resolution was considered important in this case</li>
<li>A conscious design decision was made by inserting&nbsp;line breaks in the headings (H1 and H2) directly in HTML rather than using CSS, as no reusable logic could be applied and the use of line breaks at certain points was purely cosmetic</li>
</ul>
